Fitur Utama

Semua yang Anda
butuhkan untuk inventaris

Dibangun sederhana namun lengkap — mengelola stok barang tanpa kerumitan.

➕
Tambah Barang

Tambah barang baru atau akumulasi stok barang yang sudah ada secara otomatis tanpa duplikasi data.

✏️
Update Stok

Ubah jumlah stok barang yang sudah terdaftar dengan sekali klik dari tampilan tabel interaktif.

🗑️
Hapus Barang

Pilih barang dari tabel dan hapus dari daftar inventaris dengan konfirmasi langsung.

⚠️
Cek Stok Minimum

Filter dan tampilkan barang yang stoknya di bawah batas minimum yang Anda tentukan.

💾
Simpan Otomatis

Setiap perubahan langsung tersimpan ke file data_stok.json — tidak ada data yang hilang.

📊
Status Real-Time

Tampilan status bawah menampilkan total jenis barang dan total unit stok secara live setiap detik.

Struktur Kode

Arsitektur bersih berbasis OOP

Dipisah berdasarkan tanggung jawab — model, logika, antarmuka, dan data berjalan independen namun terhubung harmonis.

🐍 Python 3.x 🖼️ Tkinter 📄 JSON 🏛️ OOP
inventaris.py
from barang import Barang
from data_manager import simpan_data, muat_data

class Inventaris:
  def __init__(self):
    self.daftar_barang = {}
    self.load_data()

  def tambah_barang(self, nama, jumlah):
    if nama in self.daftar_barang:
      # Akumulasi stok yang ada
      self.daftar_barang[nama].jumlah += jumlah
    else:
      self.daftar_barang[nama] = Barang(nama, jumlah)
    self.save_data()

  def hapus_barang(self, nama):
    if nama in self.daftar_barang:
      del self.daftar_barang[nama]
      self.save_data()
      return True
    return False

Cara Menjalankan

Mulai dalam 4 langkah

Tidak perlu install library tambahan — Python sudah cukup.

01
Install Python

Pastikan Python 3.x sudah terinstal di sistem Anda.

python --version
02
Clone Repository

Clone atau unduh semua file ke satu folder lokal.

git clone <url-repo>
03
Masuk ke Folder

Navigasi ke direktori proyek di terminal Anda.

cd stok-monitoring
04
Jalankan Aplikasi

Eksekusi file utama dan aplikasi akan langsung terbuka.

python main.py
✅
Tidak ada dependensi eksternal

Hanya menggunakan library bawaan Python: tkinter, json, dan os. Tidak perlu pip install apapun.
